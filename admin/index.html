Ringkasan Operasional

Peserta Program

Admin memasukkan data siswa yang mengikuti Program. Bisa satu per satu atau upload Excel dengan kolom NIS, NAMA, KELAS, JENIS KELAMIN. Data siswa disimpan satu kali sebagai master; jika siswa mengikuti Program lain, NIS yang sama cukup ditambahkan ke Program tersebut.

Koreksi Penempatan: -

Ubah Penempatan Akun Peserta

Dipakai untuk koreksi akun peserta yang sudah aktif. Pilihan instansi mengikuti daftar Instansi dalam Program dan riwayat lama tidak ditimpa.

Akun Siswa

Daftar akun yang sudah diaktivasi siswa. Siswa yang baru diinput Admin tetapi belum aktivasi tetap terlihat pada tabel Peserta Program di atas.

Program Kegiatan

Kode Program dipakai siswa untuk aktivasi/gabung. Pada mode Admin-only, kode hanya bekerja untuk NIS yang sudah dimasukkan Admin ke Peserta Program.

Master Instansi

Instansi dibuat satu kali dan dapat digunakan kembali pada Program PKL tahun berikutnya.

Instansi dalam Program

Pilih Program PKL dan Instansi yang sudah terdaftar, lalu tentukan lama PKL pada instansi tersebut.

Periode instansi harus berada di dalam periode Program PKL.

Lokasi Absensi

Satu instansi dapat memiliki beberapa titik lokasi, misalnya kantor pusat, kantor cabang, pabrik, atau gudang. Admin dan Guru dapat menambah/mengoreksi titik lokasi.

Data Master

Jadwal Absensi

Pilih Program dan Instansi, lalu centang satu atau beberapa hari serta satu atau beberapa titik lokasi. Hari/lokasi yang dicentang bersama akan memakai jam yang sama. Untuk hari dengan shift berbeda (misalnya shift malam), pilih hari tersebut saja lalu simpan jam khususnya.
